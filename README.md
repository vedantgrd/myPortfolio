## 🎯 The Core Philosophy

Traditional portfolios say: *"Here are my skills, here are my projects, here is my résumé."* They are efficient, and they are forgettable. They tell you what someone can do and almost nothing about who they are.

1. **A life, in progress**: Software engineering and personal humanity belong to the same person. Neither is a side quest.
2. **One canonical home per piece**: Every essay lives in *Notebook*, every project in *Work*, culture in *Taste*, verified milestones in *Archive*, the current chapter in *Now*. Other pages preview or reference the source; they never duplicate it.
3. **Personal, not corporate**: A real face. Candid writing on mental health (*So, Suicide.*), social responsibility (*Orphanage community visit*), cinema idols, and engineering failures (*Agridrone motor harmonics*).
4. **Editorial, not monotonous**: High-contrast **Geist & Geist Mono** typography, warm deep ink surfaces (`#0d0f12`), a restrained vermilion accent (`#e1523d`), and tactile layout grids.
5. **Deterministic, not arbitrary**: The daily quote rotates by calendar day, not at random. Every listed skill links to real implementation evidence.

> **The Promise:**
> *"A life, in progress. Software and humanity, in the same place, with receipts."*

## ✨ Key Features

### 📚 For Readers

- **The Notebook**: A single destination for all writing: personal essays (*So, Suicide.*, *A Tuesday at the Orphanage*), cinema & culture (*Why We Need Heroes*), superheroes, and engineering postmortems. Each piece has a long-form reading view with formatted code snippets, quote callouts, and previous/next navigation.
- **Case-Study Work Exhibition**: A filterable catalog (AI & Systems, Hardware & IoT, Security & Systems, Interactive & Games, Web Platforms). Every case study shows the architecture, the problem, key decisions, **what broke and how it was fixed**, verified outcomes, and the real tech stack.
- **Taste & Influences**: A cultural archive featuring the 4 formative films, 4 songwriters, and 4 books that shaped the author's worldview.
- **The Living Laboratory**: Interactive instruments you can actually use: the Bullwhip AI Simulator (with real-time demand oscillation chart & safety stock dampener), the CipherLab Cryptography Workbench (Caesar, Vigenère, and Avalanche bit-flip tester), and a Project-Linked Skill Evidence Matrix.
- **Strictly Factual Archive**: A 2022–2026 chronology of education, internships, hackathons, and milestones, each linking back to its canonical source.
- **Right Now**: A public snapshot of what is being built, learned, consumed, and thought about, with a **deterministic daily quotation**.
- **Direct Transmission & Private Inbox**: Direct message transmission with instant feedback, verified social links, prefilled email dispatch, and a passkey-protected `/admin` inbox subsystem for private message review.

### ✍️ For the Author

- **No CMS, one-file publishing**: Add an article, a film, a milestone, or a "now" update by editing a single typed data file. The site updates itself.
- **Auto-generated routes**: Every article gets its own shareable `/writing/[slug]` route and is indexed automatically.
- **Canonical linking**: The Archive links to `/work/[slug]` and `/writing/[slug]`, so facts live in exactly one place.
- **Permanent redirects**: `/cinema` → `/taste` and `/ordinary-days` → `/archive`, so old links never break.
- **Type safety end to end**: TypeScript 5.7 across routes, data, and components.

## 🏗️ Architecture & Tech Stack

A **Next.js App Router** site where all content lives in typed data files.

```
myPortfolio/
├── app/                  # App Router: every canonical route in the sitemap
├── components/           # UI components, simulators, visual frames, navigation
├── data/                 # writing.ts · taste.ts · archive.ts · now.ts · timeline.ts
├── hooks/                # Custom React hooks
├── lib/                  # Shared utilities
├── public/               # Static assets & resume.pdf
├── styles/               # Global styles and design tokens
├── next.config.mjs       # Next.js config and permanent redirects
├── postcss.config.mjs    # Tailwind CSS 4 via @tailwindcss/postcss
├── tsconfig.json
├── pnpm-lock.yaml
└── package.json
```

## 🚀 Getting Started

**Prerequisites:** Node.js 20+ (required by Next.js 16) and [pnpm](https://pnpm.io/) or [npm](https://nodejs.org/).

### Step 1: Clone the repository

```bash
git clone https://github.com/vedantgrd/myPortfolio.git
cd myPortfolio
```

### Step 2: Install dependencies

```bash
pnpm install
# or
npm install
```

### Step 3: Start the dev server

```bash
pnpm dev
# or
npm run dev
```

Open [`http://localhost:3000`](http://localhost:3000).

### Step 4: Build for production

```bash
npm run build
npm run start
```

## ✍️ Publishing Guide

| To do this | Open | Then |
|---|---|---|
| 📝 Publish an article | `data/writing.ts` | Add an entry to the `articles` array. It appears in `/writing`, gets its own `/writing/[slug]`, and is indexed automatically. |
| 🎬 Update Taste | `data/taste.ts` | Append a film, artist, or book. |
| 🗓️ Add a milestone | `data/archive.ts` | Append a dated, factual entry with a canonical link to `/work/[slug]` or `/writing/[slug]`. |
| 📍 Update the present | `data/now.ts` | Edit `building`, `learning`, or `consuming`. |
| 🎓 Update Academic & Journey | `data/timeline.ts` | Add an entry with dates, summary, and verification details. |
